# 6. Resources

## Keep learning

- [GitHub Docs: Hello World guide](https://docs.github.com/en/get-started/quickstart/hello-world) — a short, official version of what we just did
- [GitHub Docs: About pull requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests)
- [Git cheat sheet (GitHub Education)](https://education.github.com/git-cheat-sheet-education.pdf) — the Terminal commands behind everything we clicked today
- [Markdown Guide](https://www.markdownguide.org/basic-syntax/) — formatting for the `.md` files we've been editing

## Where to go if you get stuck later

- Re-open this repository — the `guide/` folder will still be here.
- GitHub's own docs (linked above) are searchable and beginner-friendly.
- Reach out to today's facilitator with questions as they come up.

## What's next, if you want to go further

- Practice by starting a real repository for a project you're already
  working on — meeting notes, a shared reading list, a source list for a
  story.
- Try the same fork → branch → Pull Request loop with a friend or colleague
  on a real document.
- Look into `.gitignore` and repository templates once you're managing more
  than a couple of files.

Thanks for participating — nice work today.
