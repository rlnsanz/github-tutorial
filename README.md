# github-tutorial
Getting started with Git and GitHub in 90 minutes.

In this tutorial, we will walk you through the basics of settings up your environment and creating a GitHub account, creating and updating your first repository, and publishing changes to GitHub.

Then, once we gain some familiarity with the git basics, we will publish our changes and visit one another's repositories. A simple "hello world" scenario has the participants cloning or forking repositories, making changes, addings suggestions or comments, and creating a pull request.
